# Java — Práticas

Projetos de console para praticar fundamentos de Java, do básico ao intermediário.

| # | Projeto | Conceitos praticados |
|---|---|---|
| 01 | Conversor de temperatura | `do-while`, `switch`, métodos com retorno, validação de entrada com `Scanner` |

## Como executar
```bash
javac Temperatura.java
java Temperatura
```
